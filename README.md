# kr2-bootstrap-shop

Интернет-магазин диванов на Bootstrap 5.

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Это отдельная реализация предметной области (интернет-магазин), а не адаптация КР №1: вся вёрстка построена на Bootstrap-компонентах, а `custom.css` содержит только фирменные доработки.

## Краткое описание

Многостраничный сайт магазина диванов: главная страница с hero-блоком и преимуществами, каталог товаров, страница товара, форма заявки (отдельная страница и модальное окно), контакты.

## Используемый фреймворк

Bootstrap 5.3.8.

## Подключение Bootstrap

Bootstrap подключён **локально**, без CDN. Файлы фреймворка лежат в `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css` — подключается в `<head>`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — подключается перед закрывающим `</body>`.

Собственный `css/custom.css` подключается **после** Bootstrap, чтобы переопределять его стили. Bootstrap JS Bundle нужен для работы navbar (мобильное меню), dropdown, modal, accordion, tabs и carousel.

## Реализованные Bootstrap-компоненты

- сетка: `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*`;
- `navbar` (с раскрывающимся мобильным меню) и `dropdown`;
- `breadcrumb`;
- `card`;
- `btn` и его варианты (`btn-primary`, `btn-outline-*`, `btn-lg`);
- `badge`;
- `alert`;
- `modal` — форма заявки;
- `form-control`, `form-select`, `input-group`, `form-check`, валидация `was-validated` / `invalid-feedback`;
- `accordion` — вопросы и ответы на главной;
- `nav-tabs` / `tab-content` — описание, характеристики и доставка на странице товара;
- `carousel` — «Другие модели» на странице товара;
- `pagination` — каталог;
- `list-group`, `table`.

## Форма заявки

Поля: имя, e-mail, телефон, товар или тема заявки, комментарий, согласие на обработку данных, кнопка отправки. У всех полей есть `label` и `name`, обязательные помечены `required`. Форма проверяется встроенной HTML-валидацией и показывает Bootstrap-подсказки об ошибках. Серверной части нет: после успешной проверки показывается сообщение об отправке (`alert`).

## Самостоятельные доработки

- Bootstrap подключён локально (`vendor/bootstrap/`), без CDN.
- Страница товара: вкладки (`tabs`) с описанием, характеристиками и доставкой; карусель (`carousel`) других моделей.
- Главная: hero-блок с фоновым изображением, карточки преимуществ, `accordion` с вопросами и ответами.
- Кнопка «Заказать» открывает модальное окно сразу с выбранным товаром (`js/main.js`).
- Страница контактов с картой.
- Кнопка «Наверх» и липкая панель фильтров на широких экранах (`custom.css`).
- Лёгкая адаптивность: карточки идут в 3, 2 или 1 колонку, форма и блоки страниц складываются в одну колонку, меню на узком экране сворачивается в «бургер».

## Как проверить проект

1. Открыть `index.html` в браузере (или запустить `python3 -m http.server` в папке проекта и открыть `http://localhost:8000`).
2. В DevTools (F12) включить режим адаптивного просмотра и проверить ширины 375, 768 и 1200 px: карточки перестраиваются (1, 2, 3 в ряд), меню сворачивается, горизонтальной прокрутки нет.
3. Нажать «Заказать» — открывается окно с выбранным товаром; отправить пустую форму (появятся ошибки), затем заполнить и отправить (появится уведомление).
4. На странице товара переключить вкладки и листать карусель.
